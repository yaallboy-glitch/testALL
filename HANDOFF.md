# Handoff — rakyat-kecil

## Dibuat
Redesign landing page Rakyat Kecil dengan arah editorial majalah: permukaan kertas hangat, tipografi serif/sans, aksen bata, dan hierarchy berbasis daftar/angka.

## File diubah
- `style.css`: token visual, layout editorial, warna terang, state komponen, reveal transition.
- `script.js`: IntersectionObserver reveal dengan stagger ringan.

## Cara cek
- `node --check script.js`
- `PROYEK=rakyat-kecil pw ~/.local/bin/cekweb.js index.html`

## Catatan
Referensi Hermes `good-web-design.md` hanya berisi placeholder; keputusan layout mengikuti brief redesign dan PRD proyek.
